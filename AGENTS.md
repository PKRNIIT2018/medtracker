# AGENTS.md

## Working style
- Plan before coding for any change touching multiple files.
- Keep updates concise and action-oriented.
- Prefer commands and reproducible scripts over manual steps.
- Explain decisions in plain English, not jargon-heavy prose.

## Delivery loop
1. Plan
2. Implement
3. Review
4. Test
5. Document

## Coding standards
- Reuse existing project patterns.
- Minimize dependencies.
- Keep functions small and names boring.
- Add comments only where intent is not obvious.

## Output format
- Goal
- Plan
- Changes made
- Risks
- Verification
